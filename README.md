# Kalman Filter - Sensor Fusion Simulation 📡

A Python simulation of a Kalman Filter for GPS noise reduction.

## What it does
- Simulates noisy GPS sensor data with real position
- Implements Kalman Filter to estimate true position
- Used in drones, robots and self-driving cars
- Visualizes true position vs noisy GPS vs filtered estimate

## Tools Used
- Python 3.12
- NumPy
- Matplotlib

## How to Run
pip install numpy matplotlib
python kalman_filter.py

- Sensor Fusion
